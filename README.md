# Rohan Chaudhary Portfolio
## 📌 Features

- **Glassmorphism Design** – Frosted glass panels with blur effects and gradient accents.
- **Interactive 3D Background** – Three.js powered animated scene (see `script.js`).
- **Floating Social Buttons** – Animated icons with staggered hover effects.
- **Fully Responsive** – Mobile-friendly layout using Tailwind CSS.
- **Smooth Scrolling** – Navigation links with smooth scroll behavior.
- **Skills Showcase** – Tech stack displayed with Devicon icons and hover animations.
- **Project Cards** – Showcase your work with links to GitHub and live demos.
- **Contact Form** – Simple, styled form (frontend only – add backend integration as needed).
- **Custom Animations** – Gradient text, floating icons, and card hover effects.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **Tailwind CSS** – Utility-first styling
- **CSS3** – Custom animations and glass effects
- **JavaScript (ES6)** – Interactivity (including Three.js)
- **Three.js** – 3D background animation
- **Devicon** – Tech stack icons
- **Font Awesome** – Social media icons
- **Google Fonts (Inter)** – Typography
